# TAC Operator README Policy - 2026-05-22

## English

Every README created or edited in this project must include English, French, Spanish, Korean, and Chinese sections in the same file. This applies even when the user does not repeat the instruction. Third-party vendored README files are excluded.

Reason: the controller is intended to become an operating layer. Operator-facing instructions must remain understandable across the user's preferred language set and should not depend on a single session's memory.

## Français

Chaque README créé ou modifié dans ce projet doit contenir des sections en anglais, français, espagnol, coréen et chinois dans le même fichier. Cette règle s'applique même si l'utilisateur ne la répète pas. Les README tiers fournis comme vendored sont exclus.

Raison : le contrôleur doit devenir une couche d'exploitation. Les consignes destinées à l'opérateur doivent rester compréhensibles dans l'ensemble de langues préféré par l'utilisateur et ne doivent pas dépendre de la mémoire d'une seule session.

## Español

Cada README creado o modificado en este proyecto debe incluir secciones en inglés, francés, español, coreano y chino en el mismo archivo. La regla aplica aunque el usuario no la repita. Los README de terceros incluidos como vendored quedan excluidos.

Motivo: el controlador está pensado como una capa operativa. Las instrucciones para el operador deben seguir siendo comprensibles en el conjunto de idiomas preferido por el usuario y no depender de la memoria de una sola sesión.

## 한국어

이 프로젝트에서 README 파일을 새로 만들거나 수정할 때는, 사용자가 다시 말하지 않아도 영어, 불어, 스페인어, 한국어, 중국어 5개 언어 섹션을 같은 파일 안에 반드시 포함합니다. 외부 vendored README는 예외입니다.

이유: 이 컨트롤러는 운영 레이어가 되는 것이 목표입니다. 사용자가 실제로 쓰는 안내문은 세션 기억에 의존하지 않고, 정해진 언어 세트로 계속 읽을 수 있어야 합니다.

## 中文

本项目中新建或修改任何 README 时，必须在同一文件中包含英文、法文、西班牙文、韩文和中文五种语言的说明。即使用户没有再次说明，也必须遵守。第三方 vendored README 除外。

原因：该控制器的目标是成为一个操作层。面向操作者的说明必须在用户指定的语言集合中保持可读，而不能依赖单次会话记忆。
